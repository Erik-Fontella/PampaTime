# PampaTime

> Aplicação web desenvolvida em **TypeScript** para gestão de tempo, produtividade e organização de atividades.

## 📌 Sobre o projeto

O **PampaTime** é um projeto focado em facilitar o acompanhamento de tarefas e tempo, oferecendo uma experiência simples, moderna e eficiente para o dia a dia.

## ✨ Funcionalidades

- ✅ Cadastro e gerenciamento de tarefas
- ⏱️ Controle de tempo por atividade
- 📊 Visualização de progresso
- 🎯 Organização por prioridades/status
- 💾 Persistência de dados

## 🛠️ Tecnologias utilizadas

- **TypeScript** (principal)
- **CSS**
- **Firebase**
- Outras dependências do ecossistema JavaScript/TypeScript
